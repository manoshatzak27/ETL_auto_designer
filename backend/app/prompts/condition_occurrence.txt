Populate the CONDITION_OCCURRENCE table by reading from the staging stem_table and filtering to domain_id == 5.

Input:  ETL_OUTPUT_DIR/stem_table.csv  (semicolon-delimited, UTF-8)
Output: ETL_OUTPUT_DIR/condition_occurrence.csv (semicolon-delimited, UTF-8)

Column mapping (stem_table → condition_occurrence):
  condition_occurrence_id       ← sequential integer starting at 1
  person_id                     ← person_id (use the cast from the PERSON ID TYPE section)
  condition_concept_id          ← concept_id (int, 0 if null/empty)
  condition_start_date          ← start_date
  condition_start_datetime      ← start_datetime (None if blank)
  condition_end_date            ← end_date (None if blank)
  condition_end_datetime        ← end_datetime (None if blank)
  condition_type_concept_id     ← type_concept_id (int, 32879 if null/empty)
  condition_status_concept_id   ← value_as_concept_id (int or None if blank)
  stop_reason                   ← None
  provider_id                   ← provider_id (int or None if blank)
  visit_occurrence_id           ← visit_occurrence_id (int or None if blank)
  visit_detail_id               ← visit_detail_id (int or None if blank)
  condition_source_value        ← source_value
  condition_source_concept_id   ← source_concept_id (int, 0 if blank)
  condition_status_source_value ← value_source_value

Filter logic:
  - Only include rows where domain_id is not null/blank AND int(domain_id) == 5
  - Skip rows where person_id is null/blank

Numeric safety: wrap every int/float cast in try/except, fall back to 0 or None as appropriate.
