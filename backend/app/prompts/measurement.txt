Populate the MEASUREMENT table by reading from the staging stem_table and filtering to domain_id == 1.

Input:  ETL_OUTPUT_DIR/stem_table.csv  (semicolon-delimited, UTF-8)
Output: ETL_OUTPUT_DIR/measurement.csv (semicolon-delimited, UTF-8)

Column mapping (stem_table → measurement):
  measurement_id                ← sequential integer starting at 1
  person_id                     ← person_id (int)
  measurement_concept_id        ← concept_id (int, 0 if null/empty)
  measurement_date              ← start_date
  measurement_datetime          ← start_datetime (None if blank)
  measurement_time              ← None
  measurement_type_concept_id   ← type_concept_id (int, 32879 if null/empty)
  operator_concept_id           ← operator_concept_id (int or None if blank)
  value_as_number               ← value_as_number (float or None if blank)
  value_as_concept_id           ← value_as_concept_id (int or None if blank)
  unit_concept_id               ← unit_concept_id (int or None if blank)
  range_low                     ← range_low (float or None if blank)
  range_high                    ← range_high (float or None if blank)
  provider_id                   ← provider_id (int or None if blank)
  visit_occurrence_id           ← visit_occurrence_id (int or None if blank)
  visit_detail_id               ← visit_detail_id (int or None if blank)
  measurement_source_value      ← source_value
  measurement_source_concept_id ← source_concept_id (int, 0 if blank)
  unit_source_value             ← None
  unit_source_concept_id        ← None
  value_source_value            ← value_source_value
  measurement_event_id          ← None
  meas_event_field_concept_id   ← None

Filter logic:
  - Only include rows where domain_id is not null/blank AND int(domain_id) == 1
  - Skip rows where person_id is null/blank

Numeric safety: wrap every int/float cast in try/except, fall back to 0 or None as appropriate.
