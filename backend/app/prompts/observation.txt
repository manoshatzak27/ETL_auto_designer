Populate the OBSERVATION table by reading from the staging stem_table and filtering to domain_id == 2.

Input:  ETL_OUTPUT_DIR/stem_table.csv  (semicolon-delimited, UTF-8)
Output: ETL_OUTPUT_DIR/observation.csv (semicolon-delimited, UTF-8)

Column mapping (stem_table → observation):
  observation_id                ← sequential integer starting at 1
  person_id                     ← person_id (int)
  observation_concept_id        ← concept_id (int, 0 if null/empty)
  observation_date              ← start_date
  observation_datetime          ← start_datetime (None if blank)
  observation_type_concept_id   ← type_concept_id (int, 32879 if null/empty)
  value_as_number               ← value_as_number (float or None if blank)
  value_as_string               ← value_as_string (None if blank)
  value_as_concept_id           ← value_as_concept_id (int or None if blank)
  qualifier_concept_id          ← None
  unit_concept_id               ← unit_concept_id (int or None if blank)
  provider_id                   ← provider_id (int or None if blank)
  visit_occurrence_id           ← visit_occurrence_id (int or None if blank)
  visit_detail_id               ← visit_detail_id (int or None if blank)
  observation_source_value      ← source_value
  observation_source_concept_id ← source_concept_id (int, 0 if blank)
  unit_source_value             ← None
  qualifier_source_value        ← None
  value_source_value            ← value_source_value
  observation_event_id          ← None
  obs_event_field_concept_id    ← None

Filter logic:
  - Only include rows where domain_id is not null/blank AND int(domain_id) == 2
  - Skip rows where person_id is null/blank

Numeric safety: wrap every int/float cast in try/except, fall back to 0 or None as appropriate.
