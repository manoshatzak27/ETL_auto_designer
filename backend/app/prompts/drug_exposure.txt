Populate the DRUG_EXPOSURE table by reading from the staging stem_table and filtering to domain_id == 3.

Input:  ETL_OUTPUT_DIR/stem_table.csv  (semicolon-delimited, UTF-8)
Output: ETL_OUTPUT_DIR/drug_exposure.csv (semicolon-delimited, UTF-8)

Column mapping (stem_table → drug_exposure):
  drug_exposure_id              ← sequential integer starting at 1
  person_id                     ← person_id (use the cast from the PERSON ID TYPE section)
  drug_concept_id               ← concept_id (int, 0 if null/empty)
  drug_exposure_start_date      ← start_date
  drug_exposure_start_datetime  ← start_datetime (None if blank)
  drug_exposure_end_date        ← end_date if not blank, else start_date
  drug_exposure_end_datetime    ← end_datetime (None if blank)
  verbatim_end_date             ← end_date (None if blank)
  drug_type_concept_id          ← type_concept_id (int, 32879 if null/empty)
  stop_reason                   ← None
  refills                       ← None
  quantity                      ← quantity (float or None if blank)
  days_supply                   ← None
  sig                           ← None
  route_concept_id              ← None
  lot_number                    ← None
  provider_id                   ← provider_id (int or None if blank)
  visit_occurrence_id           ← visit_occurrence_id (int or None if blank)
  visit_detail_id               ← visit_detail_id (int or None if blank)
  drug_source_value             ← source_value
  drug_source_concept_id        ← source_concept_id (int, 0 if blank)
  route_source_value            ← None
  dose_unit_source_value        ← value_source_value

Filter logic:
  - Only include rows where domain_id is not null/blank AND int(domain_id) == 3
  - Skip rows where person_id is null/blank

Numeric safety: wrap every int/float cast in try/except, fall back to 0 or None as appropriate.
